KEDAI MAHEZZ - FILE SEO

Upload ke root/domain kedaimahezz.cfd:
- index.html
- robots.txt
- sitemap.xml
- folder assets/ beserta seluruh isinya

File index-original.html hanya cadangan dan TIDAK perlu di-upload.

Sesudah upload:
1. Buka https://kedaimahezz.cfd/ dan cek foto/menu/tombol.
2. Buka https://kedaimahezz.cfd/robots.txt
3. Buka https://kedaimahezz.cfd/sitemap.xml
4. Di Google Search Console, submit sitemap.xml dan Request Indexing untuk homepage.
